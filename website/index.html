Hello, Kodas

-- Hello World in Kodas
let name = "World"
show "Hello, {name}!"

-- Pattern matching
match status {
    200 => show "OK"
    404 => show "Not found"
    _   => show "Other"
}

-- Error pipe
let data = read_file("config.json")
    |?> parse_json
    |?> validate
    |?> fn(d) => d.name

Why Kodas?

🚫 No nulls

maybe T + empty makes null pointer exceptions impossible.

🔗 Error pipe

|?> chains fallible operations without try/catch nesting.

⚡ Concurrency

flow and together make async code read like straight-line code.

🧪 Built-in testing

test "..." { assert ... } — no external test framework needed.

🌐 Web framework

Built-in HTTP server, routing, JSON, and WebSockets.

📦 Kargo

Built-in package manager with a public registry.
