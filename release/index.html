The cheat sheet.

  

    
let / let mut
Immutable by default. Add mut when a value needs to change.

    
Optional types
Type annotations are optional. KODAS is duck-typed at runtime.

    
struct · enum · trait
Plus impl, with default methods.

    
fn and give
fn name(p: T = d) -> R { give x } where give means return.

    
dyn
dyn("Trait", v) boxes a value with a vtable for dynamic dispatch.

    
match · closures
match x { Pat => body, _ => fallback } and fn(x) { x * 2 }.

Questions.

  

    
What is KODAS?
A programming language by independent developer Mudasir Ali. Source files end in .kds, and the compiler turns them into C.

    
How do I run a program?
kodas run file.kds compiles to C and runs it. kodas build file.kds produces a standalone native binary.

    
Do I have to write types?
No. Annotations are optional, and KODAS is duck-typed at runtime. Add them where they help you.

    
How fast is it?
At v0.17, recursive fib(35) takes 0.76 seconds, against 0.81 for Python 3, 0.07 for Node.js and 0.01 for C. KODAS is now faster than Python on recursive calls.

    
What does give mean?
It is return. fn name() { give value } hands value back to the caller.

    
Who are Kun and Morty?
The two mascots. Kun the cloud guides the web side of KODAS, and Morty the dog guides the computer side.

    
Where do I get it?
Scroll up to Get KODAS, or grab it from the top of the page — Linux and Windows are available today, macOS is coming in v0.17.
